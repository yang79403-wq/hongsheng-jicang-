# 洪盛集藏资讯网

钱币收藏交流服务平台 MVP。

## 核心功能
- 钱币收藏资讯
- 福建钱币资料库
- 行情价格表与涨跌
- 品相/版别知识
- 免费鉴定交流入口
- PCGS / NGC / PMG / 华夏评级送评咨询
- 回收、寄卖、上门交流服务展示
- 每日行情数据自动采集框架
- 数据来源记录、更新时间、异常标记

## 数据采集说明
项目内置 `app/scraper.py` 作为“来源适配器”。默认设计为：
1. 定时访问公开可访问页面；
2. 解析允许公开展示的行情字段；
3. 清洗为统一结构；
4. 写入 SQLite；
5. 前端读取统一行情接口。

正式上线前，应确认钱币天堂、一尘网的 robots.txt、服务条款、页面访问权限及数据使用授权；不要绕过登录、验证码、反爬或访问控制，也不要批量复制受版权保护的帖子/图片。

## 本地运行
Python 3.11+

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

浏览器打开 http://127.0.0.1:8000

## 每日自动更新
Linux/云服务器可使用 cron：
```cron
15 7 * * * cd /path/hongsheng_jicang && /usr/bin/python -m app.scheduler
```
